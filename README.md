# @sv5ui/scheduler

Scheduler and calendar library for Svelte 5. Month, week, day and agenda views, drag and drop, full keyboard access, i18n and RTL — plus an optimistic mutation pipeline that handles rollback, queueing and conflicts for you. DST-correct and SSR-safe.

> Under active development. Not yet published.

## Development

```sh
pnpm install
pnpm dev
pnpm test
pnpm lint
```
